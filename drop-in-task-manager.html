Ayuda — Cómo usar este archivo

Este es un archivo HTML drop-in. Cópialo a cualquier carpeta de proyecto y ábrelo con doble clic (file://). No necesita servidor.

La IA orquestadora actualiza SOLO el bloque #tm-state en JSON. Todo lo visual se recalcula desde ahí.

  • Copia drop-in-task-manager.html a la raíz del proyecto
  • Asigna una IA: "actualiza el task manager según avances"
  • La IA edita solo el JSON island y guarda el HTML
  • Recarga el archivo en el navegador para ver progreso
